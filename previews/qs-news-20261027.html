If every new AI request starts with you explaining the same job again, the useful decisions are probably living in old chats. A small working file gives the next request somewhere better to begin.

Give the job a memory

The first time you ask AI to help with a recurring job, you do the hard thinking yourself. You explain what good looks like, show an example, correct a bad assumption and make a few decisions. Then the chat disappears into the pile, and next time you start again.

The working file

A prompt tells AI what to do once. A working file records what the job has already learned: the aim, examples, decisions and questions that still need an answer. It is not a bigger prompt. It is the job's memory, kept where a person can read and improve it.

Fictional example: Maya runs a small events business. In a blank chat, she asks for a proposal for a 60-person breakfast and gets a fluent answer that assumes a sit-down meal, three suppliers and a formal tone. She corrects it, but those decisions stay in the chat. In her working file, the next request starts with two real proposals, one failed example, decisions already made and open questions. The file does not make the answer right by itself. It makes the important context visible before the next draft begins.

A working file keeps the useful context for the next time you do the job.
  • the job's aim, in one sentence
  • two real examples that show what good looks like
  • one example that failed, with the reason
  • decisions already made
  • questions still open

Choose one job you repeat, make this file once, and add to it after the next job. If a decision keeps being re-explained, it belongs in the file. If a question has been answered, record the answer. That is how the file becomes more useful than a fresh prompt without becoming a long manual.

Google's 5 October 2026 announcement makes this easier to maintain with other people: Google Docs can now open, edit and let people collaborate on Markdown files while keeping the .md file type. Before that, importing Markdown into a Doc could alter formatting, strip comments and fragment files. Use that option if other people need to edit the file with you.

After the next job, read the file before you ask AI again. Did it contain a decision that saved you from explaining the same thing? If not, add the missing example or decision, rather than another paragraph of generic instructions.
